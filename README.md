Este projeto consiste na criação de uma página de **Portfólio / Currículo Web**, desenvolvida com **HTML5 puro e semântico**.

A atividade tem como objetivo organizar informações pessoais, habilidades, projetos e dados de contato em uma página estruturada, funcional e seguindo a organização apresentada no modelo proposto.

---

<div align="center">

[![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&size=24&duration=8000&pause=1500&startDelay=0&color=E34F26&center=true&vCenter=true&width=750&lines=🎯+Objetivo+da+Atividade)](https://git.io/typing-svg)

</div>

Criar uma página HTML **limpa, semântica e funcional**, reproduzindo a estrutura de um currículo/portfólio pessoal e demonstrando o domínio dos principais elementos de **HTML5**.

---

<div align="center">

[![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Fira+Code&size=24&duration=8000&pause=1500&startDelay=0&color=E34F26&center=true&vCenter=true&width=750&lines=📝+Elementos+Implementados)](https://git.io/typing-svg)

</div>

- 🧭 **Cabeçalho e navegação:** título principal com nome/cargo e menu com links internos.
- 👤 **Sobre Mim:** foto de perfil com dimensões de **150x150px**, apresentação e lista de habilidades.
- 💻 **Meus Projetos:** tabela com Projeto, Tecnologias, Status e Link.
- 📩 **Entre em Contato:** formulário organizado dentro de um fieldset com o título **Dados do Contato**.
- 📝 **Campos do formulário:** Nome, E-mail, Assunto, Mensagem e botão de envio.
- 📌 **Rodapé:** direitos autorais com &copy;, e-mail e telefone.
